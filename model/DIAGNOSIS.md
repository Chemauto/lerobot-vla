# 🩺 ACT 15,000 步排查

**接线检查通过，但模型的动作精度和闭环稳定性不足，完整四方块任务仍未解决。**

## ✅ 已核实

- 第 0、40 条示范的动作原样回放：均为 **4/4 入盒**，每步关节状态、最终 qpos 与记录完全一致。动作单位、顺序、频率和初始状态在这两个样本上对齐。
- 相机按采集配置加载；训练与播放都使用同一 checkpoint 的归一化。实时图像与数据集解码图像存在 H.264 压缩差异，并非逐像素相同。
- 在两条示范的前两次抓放中抽取 **64 个观测**，正常输入的前 10 步关节目标平均绝对误差约 **1.68°**。第一步关节目标经运动学换算后，夹爪参考点的位置误差平均 **7.99mm**，90 分位 **11.47mm**。这是目标位姿误差，不是直接测得的闭环接触误差。
- 开局抽查发现肩、肘预测偏差约 8–10°。在同一批抽样点，将归一化图像置零或将归一化关节状态置零，预测误差均明显上升，模型确实依赖两类输入。

## ⚠️ 失败表现与对照

原模型每次执行 10 步再预测。在 3 个卡住的场景中，84%–90% 的腕关节目标超过 95° 上限，且夹爪从未进入 `<30` 的闭合区间。环境会裁剪目标，这些场景无法继续完成抓取。

| 对照实验 | 观察结果 |
|---|---|
| 10 步执行，4 场景，各 1,200 步 | 入盒数：0、0、0、1 |
| 50 步执行，相同种子，各 1,200 步 | 入盒数：0、1、1、1 |
| 50 步执行，再跑完整 3,600 步回合 | 入盒数：0、0、1、0，完整成功 0/4 |
| 官方时间融合，种子 240，3,600 步 | 放进 2 块，完整任务仍失败 |
| 从原权重集中训练第 0 条示范 1,000 步 | 训练 L1 从约 0.065 降到 0.050，但该固定场景仍为 0 块入盒 |

执行方式会改变行为，但目前没有可靠的完整任务提升，**不能把短测的部分进展当成修复**。单条示范实验的归一化统计与原模型一致；这个有限实验也不能证明更长训练一定无效。

## 🎲 重复性限制

同一份输入连续前向计算，结果完全一致；相同种子重置后，OpenGL 仍有极少数像素相差 1 个灰度值。重复 600 步试验中，这类小差异被策略和物理接触逐渐放大。因此增加 PyTorch 确定性设置有助于控制计算变量，但不能承诺整条仿真逐位一致，也不能据一次种子测试判定参数优劣。
